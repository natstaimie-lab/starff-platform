# Brand

The written record of Starff's brand decisions, so designs stop drifting.

`brand-sheet.md` is not written yet — it needs the exact hex values and font
names pulled from the Canva flyer, plus the three pending decisions listed in
the top-level README.

What is already established, from the existing flyer and starff.co.uk:

- Deep navy background, orange accent, white text
- Dot-cluster "S" mark with a STARFF wordmark
- Headline device: two lines, the second in orange
  ("Short staffed? / **Get Starffed.**")
- `FOR EMPLOYERS` / `FOR CANDIDATES` corner tag — one brand, two audiences
- Voice: short sentences, numbers over adjectives, no jargon

There is no Canva brand kit set up yet. Creating one (Canva Pro, in the Canva
UI) is the highest-leverage task here — without it every design re-picks
colours by hand.
